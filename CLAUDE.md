# MAST — shared repository instructions

For code review or development, read [AGENTS.md](AGENTS.md) first.

These shared instructions map the system's engineering mechanisms to implementation
and regression tests, and explain how to review and extend this public source edition.

[docs/OPEN_SOURCE_NOTES.md](docs/OPEN_SOURCE_NOTES.md).
