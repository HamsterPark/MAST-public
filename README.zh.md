# MAST — 模块化自主扫描探针显微实验工具包

[English](README.md) · **中文**

**让 AI 在原子尺度的真实实验中观察、推理、行动，并检验行动的结果。**

MAST 面向扫描隧道显微镜（STM），将多智能体协作、仪器控制、视觉观测、数据分析与操作员界面连接起来，
把实验意图落实为带有执行约束、状态反馈和人工介入入口的物理操作。
它关注一个核心问题：当仪器状态不完全可见、操作会改变被测系统时，AI 如何持续获得可信数据，并据此推进实验？

## STM 是什么？

扫描隧道显微镜利用**量子隧穿**研究表面：将导电针尖靠近具有可测隧穿通道的样品，施加偏压，
测量电子穿过针尖与样品之间势垒所形成的微弱电流。针尖逐点扫描时，反馈系统通常调节针尖高度以维持设定电流，
由此形成具有原子尺度分辨能力的图像。Binnig 等人在 1982 年报告了这一方法的早期表面研究成果。
见[原始论文](https://doi.org/10.1103/PhysRevLett.49.57)；入门概览可参阅 [Wikipedia：扫描隧道显微镜](https://en.wikipedia.org/wiki/Scanning_tunneling_microscope)。

STM 图像同时包含表面几何形貌与电子结构的信息。进一步改变偏压、记录电流或微分电导，可开展扫描隧道谱（STS），
在特定位置研究局域电子态。将微分电导解释为样品局域态密度，需要针尖、隧穿势垒、温度和测量条件等近似成立，
不能把每一条谱线直接当成材料本征性质。其理论基础见 [Tersoff–Hamann 理论](https://doi.org/10.1103/PhysRevB.31.805)。

### 原子尺度精度背后的仪器条件

面向低能电子态和量子材料研究的低温、超高真空 STM，将多种极端条件集中在一个极小的隧道结上。
下列量级用于解释仪器原理，具体工作条件由样品、测量目标和仪器标定决定。

| 特点 | 为什么重要 |
|---|---|
| **极近距离的隧道结** | 针尖与样品通常仅相距数埃，即零点几纳米。电流对间距呈近似指数依赖；极小位移既能提供高分辨能力，也会显著改变信号。 |
| **极低电流** | 常见成像电流处于皮安至纳安量级，即约 $10^{-12}$ 至 $10^{-9}$ A。前置放大器、接地、线缆与带宽共同决定微弱信号能否被可靠读出。 |
| **低温乃至极低温** | 开尔文乃至毫开尔文条件可减小热展宽，支持低能态研究。冷却、热平衡与电子温度控制本身也是仪器工程的一部分。 |
| **超高真空（UHV）** | 为洁净表面、针尖制备和长时间测量提供环境，降低残余气体吸附造成的污染；真空环境仍不能保证针尖在操作中保持不变。 |
| **低机械噪声与低电噪声** | 隔振、声学隔离、电磁屏蔽与滤波共同抑制隧道结位移和电信号扰动；射频噪声还会影响电子温度和谱学分辨率。 |
| **长时间高稳定性** | 谱图和重复测量要求在数小时甚至更长时间里维持可比较的针尖状态与空间位置；热漂移、压电蠕变及针尖变化都可能破坏这种对应关系。 |

关于成像电流的典型量级，可参阅[单分子测量综述中的 STM 原理说明](https://doi.org/10.1021/nn103298x)。
这些要求已有具体仪器实现：Song 等人的设施在 10 mK 基底温度下实现了隧道结亚皮米级稳定性；
Schwenk 等人进一步讨论了极低温谱学中的热化、射频滤波与微电子伏能量分辨率。
见 [10 mK 扫描探针设施](https://www.nist.gov/publications/10-mk-scanning-probe-microscopy-facility)及
[高能量分辨率仪器设计](https://doi.org/10.1063/5.0005320)。
这些是所引文献中仪器的指标，并非 MAST 的性能声明。STM 也可在室温、空气或液体中工作；低温与 UHV 并非所有 STM 的必要条件。

## 为什么 STM 是 AI 实验科学的“皇冠明珠之一”？

**我们认为，自主 STM 是 AI 实验科学最有代表性的高难度挑战之一。**
它把原子尺度感知、物理推理、精密控制、异常诊断和实验设计放进同一个闭环。
“皇冠明珠”表达的是这一研究价值判断，而不是对所有科学仪器难度的统一排名。

### 一个只能看见部分状态、且会被操作改变的物理系统

这里最关键的隐变量是**针尖最末端的原子构型、化学状态与电子态**。
在常规 STM 操作中，我们直接读到的是针尖与样品共同产生的图像、谱线和电流，而不是针尖末端本身的真实状态。
从这些信号倒推针尖通常也没有唯一答案：不同的针尖—样品组合可能产生相似的观测。
因此，对针尖状态的判断只能是**有证据约束、但仍不确定的猜测**；增加观测可以检验或排除某些解释，却不意味着能够还原真实的微观构型。

这种未知还会随操作变化：针尖可能在扫描、脉冲或接触过程中重排、吸附物质，改变成像对比度与谱学响应。
自主系统必须始终保留对针尖状态的不确定性，并在这种不确定性下判断下一步操作是否合适。
真实 STM 原子操纵研究已明确指出针尖自发变化、操纵参数未知及针尖—原子相互作用难以准确建模的问题。
见 [Chen 等，2022](https://www.nature.com/articles/s41467-022-35149-w)。

从自主实验的角度，可以把这些物理特征归纳为五个相互关联的难点：

| 系统特征 | 在 STM 中意味着什么 | 对自主智能体的要求 |
|---|---|---|
| **部分可观测** | 针尖的真实微观状态不可直接观测，图像与谱线通常也无法将其唯一反演；多个针尖—样品状态可能给出相似的观测。 | 维护多个有证据约束的假设，持续检验其可信程度；把针尖状态当作不确定的判断，而非已经识别出的事实。 |
| **强非线性** | 电流对距离呈指数变化；电压、局域电子态、势垒和反馈共同影响响应。一个参数的小变化可能跨过成像、操纵或接触之间的边界。 | 根据当前状态与标定选择受约束的动作，不能把一次成功的参数组合视为普遍有效的配方。 |
| **非平稳** | 热漂移与压电蠕变使实际位置随时间变化，压电迟滞使电压—位移关系随此前的驱动轨迹而异；吸附与针尖重构也会改变测量响应。同样的控制指令难以始终对应固定的位置与响应。 | 持续检查位置、漂移和测量响应，重新定位、重新评估，并在必要时调整策略；不能长期沿用一次标定或一次成功的结果。 |
| **历史依赖** | 此前的修针、脉冲、接触、吸附和物质转移，会留下不同的针尖与表面状态；后续实验的结果因此取决于系统经历过什么。 | 记录动作、顺序、时间与结果；相同的当前设定值并不保证相同的物理状态。 |
| **操作改变系统** | 修针、原子操纵和局域激发会主动改变针尖或表面；测量本身也可能扰动脆弱对象。针尖重排、原子转移等变化可能不可逆，恢复参数并不等于恢复原状。 | 同时考虑动作的信息价值和物理后果，执行后重新确认测量条件，并保留中止和人工介入入口。 |

这些特征并不互斥。压电迟滞本身也体现历史依赖；这里将它与蠕变、热漂移一并放在“非平稳”中，着重说明实际坐标与控制响应难以保持不变。

距离敏感性的简单近似是 $I \propto e^{-2\kappa z}$，其中 $z$ 是针尖—样品间距，$\kappa$ 与有效隧穿势垒有关。
这解释了 STM 的高灵敏度，却不足以完整描述一台运行中的仪器：真实观测还受到针尖电子态、样品、偏压、温度、漂移和噪声的共同影响。
相关理论与扫描器非理想响应分别见 [Tersoff–Hamann](https://doi.org/10.1103/PhysRevB.31.805)及
[扫描器迟滞与蠕变研究](https://doi.org/10.1063/1.4974271)。

因此，我们把自主 STM 理解为**部分可观测决策、在线系统辨识、主动学习和精密控制的结合**。
这是一种建模视角：智能体依据观测与操作历史，对可能的状态及其可信程度形成暂时判断，同时选择能推进实验、又能检验这些判断的动作。
这里的“状态估计”始终保留不确定性，并不等于倒推出针尖的真实结构。
它不是声称已有一个完整、准确的 STM 状态模型，也不是 MAST 已实现全部自主能力的声明。

### 难点在于异常诊断、恢复与科学判断

一张“看起来很好”的图像，并不足以证明针尖适合接下来的谱学测量。
当谱线出现异常时，实验者需要区分材料电子态与针尖态、充电、针尖诱导能带弯曲、反馈或噪声等影响。
不同解释可能需要不同的对照：改变测量条件、比较扫描方向、复测参考区域，或在修针后重新定位并重复测量。
例如，半导体表面研究已经直接测量了针尖电场对能带的扰动，见[针尖—样品静电相互作用研究](https://doi.org/10.1103/PhysRevLett.70.2471)。
这里列举的是诊断思路，具体动作必须由样品条件、仪器约束和操作授权决定。

真正困难的是把这些步骤串成可靠的因果判断：发现异常，提出候选原因，选择能区分原因的观测，
执行后核对结果，再决定继续、恢复、重测还是交由操作员处理。
**自主科学判断需要先建立对测量条件的信任，再据此解释物理。**

许多操作经验以隐性知识存在：实验者知道何时应等待、哪种条纹值得警惕、修针后应验证什么，
这些依赖情境的判断，需要进一步整理为可执行、可验证的工作流程。
通用大语言模型可以拥有 STM 的原理知识，却不能仅凭这些知识获得某台仪器当前的针尖状态、标定、操作经验和可执行接口。
面向扫描探针的 AI 综述同样将专家经验依赖及自主修针、操纵与闭环实验列为重要问题。
见 [Li 等，2026](https://doi.org/10.1016/j.asi.2026.100003)。

### 从局部自动化走向闭环科学实验

已有研究展示了明确的进展：2022 年，深度强化学习用于真实 STM 中的 Ag 原子操纵，并结合路径规划完成原子组装；
2025 年，一项室温 STM 工作整合了针尖与表面判断、原子识别、区域选择、漂移修正、修针和原子操纵。
这些成果对应特定材料与任务，尚不能外推为面向未知样品的通用自主研究能力。
见 [Chen 等，2022](https://www.nature.com/articles/s41467-022-35149-w)与
[Okuyama 等，2025](https://doi.org/10.1021/acs.nanolett.5c04982)。

2026 年的自驱动扫描探针综述进一步讨论了从自动采集、实时分析和主动学习走向发现与操纵的方向。
MAST 希望为这一方向提供可检查的工程基础：让实验知识、仪器接口、执行约束、观测和工作记录能够协同工作。
见 [Narasimha 等，2026](https://doi.org/10.1021/acs.accounts.6c00273)。

长期目标是形成这样的科学闭环：**观察 → 提出假设 → 设计对照 → 受约束地执行 → 检查仪器与样品变化 → 更新证据 → 决定下一步实验**。
能否排除伪影、恢复可信测量并验证物理假设，比能否单次完成扫描更能检验一个自主实验系统的能力。
STM 的局域环境和原子尺度反馈使其成为值得研究的实验智能评测平台；这是项目的研究愿景，而非已经完成的通用“AI 科学家”。

### 长演示：仍在进行的 STM 实验

在这项独立实验中，AI 不只在后台写计划，而是在真实隧穿结上反复定位、采谱、成像，在热漂移和通信异常中继续推进实验。研究者给出科学目标与时间预算，并在补液氮时暂停实验；主要测量步骤由智能体经 MAST 自主安排，无需人工逐条下发仪器指令。

这轮实验使用 MAST **6.4.0**。截至 **2026 年 9 月 21 日 20:12:59（北京时间）**，记录延续约 **93 小时**：约 **4.3 K（−269 ℃）** 的低温环境，常用参考工作点仅 **20 pA**，亚纳米量级的隧穿间隙，早期追踪目标的形貌起伏约 **18 皮米**。4.3 K 为标称实验条件，20 pA 并非全程唯一设定点。

## 核心工程能力

MAST 的工程工作横跨 AI 编排、物理仪器、科学数据与 Web 应用。公开源码保留了以下主线：

| 工程问题 | 已实现的机制 | 代表入口 |
|---|---|---|
| 将模型动作接入物理仪器 | 技能参数范围与 SI 数量级校验、执行模式与安全检查、仪器占用权、中止处理；基础仪器技能与声明式复合流程共享执行约束 | [执行上下文](MASTv2/mast/core/execution_context.py)、[安全检查](MASTv2/mast/core/safety.py) |
| 在多个智能体之间延续实验任务 | 编排器与七个领域智能体分工；以类型化产物引用、有界摘要和状态归并传递工作成果 | [状态契约](MASTv2/mast/agents/state.py)、[产物通道](MASTv2/mast/agents/_shared/artifact_channel.py) |
| 将持续观测供给较慢的推理 | 视觉、监控与缓冲层组织仪器观测，向智能体暴露观测年龄与扫描推进状态 | [缓冲服务](MASTv2/mast/buffer/service.py)、[观测工具](MASTv2/mast/agents/_shared/buffer_tools.py) |
| 处理真实系统中的故障 | 控制器协议的分段读取、连接中断与超时处理；WebSocket 重连与轮询回退；SSE 区分完成、断流与静默超时 | [协议补丁](MASTv2/mast/core/nanonis_patch.py)、[前端流式通信](frontend/src/lib/) |
| 将能力开放给外部智能体 | 外部 API、MCP 集成和技能投稿接口；作业请求去重、内容冲突检查与重启后的状态处理 | [外部作业](MASTv2/mast/api/ext/jobs.py)、[Claude Code 集成](integrations/claude-code/README.zh.md) |

[审阅指南](AGENTS.zh.md)将这些机制逐项连接到源码与回归测试，适合人工阅读，也适合代码助手从实现出发检查项目。
MAST 通过这些机制连接推理与执行；它们本身并不保证每一次仪器诊断或科学结论都正确。

## 系统架构

**实验意图与操作员 → 多智能体协作 → 技能与复合流程 → 执行校验与安全检查 → Nanonis / STM**

**仪器观测 → 视觉与监控 → 缓冲与状态层 → 智能体推理与下一步实验**

| 层次 | 职责 |
|---|---|
| 控制器 | 承担底层实时反馈与仪器控制。 |
| 视觉、监控与缓冲 | 产生观测，整理状态，提供数据新鲜度与执行进度。 |
| 智能体与共享产物 | 完成较慢的推理、任务拆分和交接；领域智能体中由 `instrument_control` 调用仪器技能。 |
| API 与 React 操作员界面 | 呈现实验状态与结果，为操作员提供观察、介入和中止入口。 |

手动操作与外部接口各自的执行入口见审阅指南。不同层次共同连接实时控制与较慢的科学推理。
`core`、`skills`、七个领域智能体、内部 API、视觉与监控、数据读写、缓冲、签名增量更新及网络模块
均已有在维护者仪器上的功能运行经历，具体经验对应当时使用的功能与版本。
长时间规划 `conduct/`、自研运行时 `agentruntime/`、`goals/`、技能工坊与市场及 qPlus 路径仍处于实验阶段，尚待真机验证。
自研运行时与 LangGraph 路径共存，`engine_v2_*` 开关默认关闭。

进一步阅读：[智能体拓扑](docs/v2/agent-topology.md)、[技能目录](docs/v2/skill-catalog.md)、[模型服务适配](docs/api_providers/)。
