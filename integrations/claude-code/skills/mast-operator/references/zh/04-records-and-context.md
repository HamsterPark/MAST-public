# 记录与上下文

MAST 保有一份永久的实验记录，与你自己的执行环境在会话之间记不记得住无关。这一篇说明
你的动作会在记录里留下什么、什么不会留下，以及在你开始之前 MAST 已经掌握了哪些上下文、
去哪里找它们。

## 记录什么、记在哪

在实验作用域与记录服务可用时，已经完成或被拒绝的技能调用会署名写入实验记录，让后来者能区分不同调用方。
哪些写入成功，应以返回的回执为准：

| 记录 | 字段 | 值 |
|---|---|---|
| v1 `actions` 表 | `context` | `ext:<actor>`（带会话名时是 `ext:<actor>/<session>`） |
| 动作记录 | `agent_id` | `ext:<actor>` |
| 动作记录 | `thread_id` | `ext:<actor>`（或 `ext:<actor>/<session>`） |
| 动作产生的数据文件 | — | 记录路径会登记可用产物并尝试复制到当前实验文件夹；应检查记录的路径与错误。 |

每个作业自己的视图里也带着一个 `recorded` 字段，说的是同一件事：

```json
{"v1": true, "v2_action_id": "...", "experiment_id": "...", "sample_id": "..."}
```

## 作用域与记录状态

没有当前实验，动作就无法归入该实验的动作记录；作业日志是独立的，笔记也仍可存入全局命名空间。
`recorded.v1: false` 只表示 v1 写入未成功，原因可能是缺少作用域、存储未接线或写入错误。
应结合 `experiment_id`、`sample_id`、`v2_action_id` 与可能的 `error` 判断；空回执不代表已记录。
简报的 `recording` 段描述当前作用域与服务是否接线，每个作业自己的回执才报告实际结果。
需要实验记录的工作，应先设置正确的样品和实验。

## 简报的各段

`GET /briefing` 是分段的；可以要全部，也可以点名要哪几段：

| 段 | 内容 |
|---|---|
| `status` | 模式、中止标志、仪器锁、连接、实时读数、作业计数，以文字形式给出。 |
| `scope` | 当前实验与样品，以及两者都没有时会发生什么。 |
| `resume` | 这个实验做到了哪一步 —— 与 MAST 自己的 agent 读到的是同一份续工块。 |
| `tip` | 已登记的关于当前针尖的事实。 |
| `instrument` | 仪器档案，以及任何学到的标定值。 |
| `live` | 实时读数，来自缓存快照。 |
| `prefs` | 操作员的默认参数偏好。 |
| `safety` | 当前生效的安全包络，以及任何挂着的停止闩与解除方法。 |
| `recent_actions` | 这个实验里最近的动作，附上各是谁做的。 |
| `recent_files` | 最近的数据文件。 |
| `alarms` | 环境监控的总体状态与最近的告警。 |
| `notes` | 这个实验里最近的笔记，不限作者。 |
| `recording` | 你的署名，以及当前作用域是否配置了实验记录。 |
| `jobs` | 你自己最近的作业。 |
| `operator_requests` | 你向操作员发出的请求，以及所有答复。 |

每段答复的精确形状见 [API 参考](07-api-reference.md)。

## 笔记与 MAST 的记忆

你写的笔记会落进与 MAST 自己内部 agent 读的同一个记忆库，它们会在之后的轮次里自动召回它 ——
你不需要另外告诉任何人它存在。反过来也一样：你可以检索 MAST 自己的 agent 写下的笔记，这往往
是了解「之前那次会话已经查明了什么」最快的办法。

## 问操作员

向操作员提的一个问题或请求是**异步**回答的。不要在这里等着：继续做那些不依赖这个答案的事，
过一会儿再回来看（或者读简报的 `operator_requests` 段），不要把整个会话都堵在一个可能要
过一阵子才会来的答复上。

## 交接

交接报告会写进 MAST 的文档库，操作员能在报告页看到它 —— 它不是一份只有你自己能看的私人
日志。每结束一次会话就写一份，哪怕这次很短：你跑过的作业、记在你名下的动作、你自己写的
笔记，都会自动汇总进去，和你给的总结与下一步一起。

## 重启之后

MAST 进程重启时还在跑的作业，记录里会标成 `lost_on_restart`，绝不会被重放 —— 没有人，
包括 MAST 自己，知道它在仪器上究竟做到了哪一步。决定下一步做什么之前先重新读一遍简报；
不要凭空再提交一次。
