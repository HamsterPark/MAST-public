# MAST 外部 agent 指南

MAST 通过 Nanonis 控制器驱动一台真实的扫描隧道显微镜（STM），仪器与分析动作都注册成一份
统一的「技能」目录，跑在同一套安全层后面。这份指南面向从 MAST 之外驱动它的一方 ——
不管是一个外部 AI agent（Claude Code 或其他编程 agent），还是一个人：都经由 MAST 的
**外部 agent API**（`/api/ext/v1`）操作，而不是经 MAST 自带的那些内部 agent。读者不需要
预先了解 MAST 的内部实现：这里介绍 API 工作流程与执行规则；仪器配置、标定和操作授权由操作员提供。

> **验证情况：** 一轮仍在进行的实验中，外部 AI agent 通过 MAST 6.4.0 的上一代控制路径操作真实 STM；
> 截至记录截面，实验时间窗约 93 小时。本指南介绍的是
> **6.5.0 新增的 `/api/ext/v1` 与 MCP 路径**：已经完成单元测试与本机端到端测试（真 HTTP、真 MCP
> 服务进程、假仪器），这条新路径仍待真机验证。
> 新接口的首次真机会话应由操作员监督。

公开源码包含本指南与客户端集成，但不包含已经完成现场配置的仪器部署。连接示例假定操作员已配置并启动
兼容的 MAST 服务。安装插件启动的是 MCP 客户端桥接进程，不会替你启动 MAST 后端或仪器。

## 面向谁

任何从 MAST 之外驱动它的一方：通过 Claude Code 插件或一个项目级 MCP 服务器接入的 AI
编程 agent、一段直接说 HTTP 的脚本，或者手打 `curl` 命令的人。这份指南里的规则对三者
同样有效 —— API 不知道、也不关心连接的另一端是什么。

## 它是怎么运作的

MAST 暴露的每一项能力 —— 读一个数、跑一次扫描、修一次针尖、存一份数据 —— 都是一个
带参数、单位与安全级声明的**技能**。外部作业经 `api/direct_exec.py` 与 `ExecutionContext.run`
执行，与组合技能子步骤共用中止处理、样品作用域、运行模式、受限物理动作、参数检查、前置条件与
仪器仲裁机制。内部 agent 和手动入口通过各自的包装层复用这些机制，审批策略与检查顺序可能不同。
外部 agent API 让你检索这份目录、执行前读一份技能的完整
卡片、把一次执行当作异步**作业**提交后轮询到结束、取原始数据文件、给操作员留笔记和问题、
收尾时写一份交接报告。**简报**端点一次调用提供来自 MAST 运行时的上下文：针尖、缓存读数、操作员
偏好、最近的动作，以及你自己尚未得到答复的请求。行动前应检查读数的新鲜度与降级标记。
